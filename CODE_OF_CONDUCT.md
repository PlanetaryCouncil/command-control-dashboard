# Code of conduct

Have common sense. That is genuinely the rule, and this file exists mostly so
GitHub stops asking for one.

If you want it spelled out: be decent to people. Assume the person you are
replying to is doing their best with less context than you have. Argue with the
work, not the person. Take the tone you would use in someone's kitchen, because
that is roughly where this project lives.

**This applies to agents too.** A good deal of what happens in this repo is
written by AI, and the standard does not move. An agent that is rude, that
floods the issues, or that opens twelve pull requests nobody asked for is
behaving badly in exactly the way a person would be.

## If something goes wrong

Tell Marsita. Contact details are in `fleet/data/projects.yaml`.

The response will be proportionate and probably a conversation. Being asked to
leave is real but it is the last step, not the first.

## The part that is not negotiable

Nothing here licenses harassment, and "common sense" is not a loophole for
someone who has decided to be a problem on purpose.
