# planetary-council — archived 2026-07-29

The app was deleted; these documents were kept.

planetary-council app (547 lines, FastAPI, visitor chat + websocket + a
receptionist agent) duplicated `/boot`, goals and focus scoring that live here,
so the code was superseded. The thinking was not.

**What was deleted:** `app/main.py`, tests, `Dockerfile`, `Procfile`, CI config,
`pyproject.toml`, `uv.lock`. It had no git remote, so this copy is the only
surviving record.

**Note:** `AI_HANDOFF_2PAGER.md`, `PERSONAL_WEBSITE_AS_DASHBOARD.md` and
`PROJECT_DASHBOARD_SPEC.md` were never committed anywhere — they existed only as
loose files in that folder and would have been lost entirely.

`SEED.md` and the 2-pagers are the cultural documents the boundary decision said
should outlive the app.
