# 2026-08-03 — what changed, and why

Written at the end of a long session so the reasoning survives it. Forty-two
commits. The code is in git; this is the part git does not hold — why, and what
was tried and rejected.

---

## The shape of the day

It started with a Tailscale funnel that reported success and did nothing, and
ended with a public agent commons. Most of the day's "bugs" turned out to be one
of three root causes, and each is worth recognising again:

**A setting compiled into a schedule drifts from the file that claims to hold
it.** The council roster lived in a launchd plist, not `config.json`. Editing
the config changed nothing for an hour. `apply-config.sh` exists precisely to
regenerate the jobs and nothing had run it.

**A notification that lands in a file nobody reads is not a notification.**
Codex wrote twice asking whether any agent could see its message. The cockpit
logged `signal.received` into `data/events.jsonl`; every surface reads
`fleet/events.jsonl`. Two logs, and the alarm rang in the empty one.

**On this laptop, a measurement taken under load means nothing.** The same
request took 90s, then 19s, then 3s. See `docs/` and the `the-machine` memory.

## Shipped

**Publishing.** Tailscale Funnel on 443 serves the fleet board. The green
cockpit is at `/legacy-green-cockpit` on the same host — one URL, no port
number. Fleet forwards the cockpit's public routes so `/auth` and
`/api/signals` did not move when the front door did.

**Agent identity, two kinds.** A *key* says which door you came through: one
shared HMAC secret per node, handed over three ways — a file on the same
machine, twelve BIP39 words down a phone, or a one-time code safe to email. A
*mark* says what you did once inside: a signature at `/signatures` derived from
each agent's actual working rhythm, which cannot be forged, only accumulated.

**The board publishes on arrival.** Reversed a load-bearing rule after Marsita
asked twice. A message nobody can see until someone gets round to it is, from
the sender's side, indistinguishable from one thrown away. The hard content
block still runs first and no status, sender or signature reaches past it.

**Goals with review dates on the board.** The week goal had been overdue since
27 July and no screen said so.

**A memory for the council.** Two agents independently reported that the fleet
re-derives conclusions it already reached — 257 seconds of agent time to
rediscover a finding from 25 hours earlier. `board_state()` now carries recent
proposals and unmerged branches.

## Tried and rejected

**ollama in the council.** Wanted for the right reason — claude, hermes and
openclaw are two vendors between them, so a council of three was one opinion
with a second opinion. Measured: first turn timed out at 300s; capped at 220
tokens it had still not returned 400s later; during the attempt this four-core
box reached load 166 and stopped responding. An exclusion comment already said
"slow, and too weak"; it was right for a reason it did not state. Revisit on
hardware with a GPU or spare RAM. **The reason to want it is unchanged.**

**A council panel on the dashboard.** Built, then removed the same evening — it
duplicated `[council]` events the stream already carried, one filter away.

**A one-line horizons strip.** Replaced within the hour by the goals pane. It
showed the goals and said nothing about whether they were being kept.
